# 新 —— 感知·跟踪·干扰一体机

1.6 MHz 观测带宽、10×160 kHz 信道、3 GHz 中心。自动发现正在通信的信道并压制；
对方切频后自动跟随。

## 1. 硬件分工

| 子板 | 端口 | 用途 |
|---|---|---|
| 子板1 / ch0 | **RX2** | 感知信道 |
| 子板1 / ch0 | **TX/RX** | 发射干扰 |
| 子板2 / ch1 | **TX/RX** | 发模拟通信信号（随机 4~8 秒跳一次，随机信道） |

一个周期：先收一帧（2 ms）→ 判断目标 → 发 20 ms 干扰 → 等射频尾迹结束 → 再收。
实测周期约 36 ms，干扰占空比约 55%。

天线间距约 5 cm、无衰减器，所以 TX 增益固定 0 dB，功率只用基带幅度调
（`power_db` 0~20 → 幅度 0.025~0.25），实测满幅也不会让对端削顶。

## 3. 界面

- 左上：跟踪状态（搜索/扫描/锁定/已停止）、目标信道、跟随次数、中心频率、参数、周期
- 中间：实时频谱（红色虚线是当前目标）+ 信道状态流水：绿色=信号，
  淡红半透明=干扰覆盖（宽度等于实际带宽），重叠处绿色仍可见，深灰=空闲；顶部最新、向下滚动
- 下方：事件日志、跟踪轨迹、运行趋势（SNR/最高评分）、干扰波形预览
- 右侧：Agent 对话 + 快捷按钮（自动跟踪/停止/多音/限带噪声/功率+5/状态/态势报告）
- Agent 工具：自动跟踪、固定干扰、参数调整、切中心频率、态势分析、趋势历史、信道历史、系统信息
- 右下角：固定信道 + 固定干扰；中心频率（MHz）输入 + 切换，换频段后先停留 10 秒再扫描

## 4. 跟踪逻辑

```
搜索 ──连续2帧评分≥0.55──► 锁定 ──目标掉到0.30以下──► 找新信道
  ▲                                                    │
  └──── 连续8帧无候选 → 释放 → 扫描 9 个 1.6 MHz 块 ◄───┘
```

- 干扰机只从 `sense_frame()` 拿 IQ 数据，**不读子板2 的跳频计划**；跟随一定存在
  检测延迟，事件日志里会打印实测值（通常 1~2 个控制周期，约 50~90 ms）
- 判决有两套：窄带看邻道对比度；宽带（整段抬高、没有对比度）看相对**绝对噪声基准**的
  信噪比，超过 16 dB 即判占用。基准在启动时的安静频段自动学习，切频段后继续沿用
- 换中心频率后会先丢 20 帧再开始感知，避免把本振瞬态当成信号锁定
- 双阈值迟滞（0.55 / 0.30），避免边界抖动
- 评分里加了一个不饱和的强度项，多个占用时选最强
- 目标丢失后按 ±1.6 MHz 块扫描，处理中心频率整体搬移
- 3 帧滑窗、2 帧确认，避免误锁

## 5. 实测

| 项目 | 结果 |
|---|---|
| 离线自检 | 30/30 |
| 实机环回 | 信道 3→7→2 两次跟随，`PASS` |
| 实机周期 | 约 36 ms（干扰 20 ms） |
| 接收溢出 | 正常模式 0（同步接收 + 每轮排空） |

## 6. 已知问题

- 目标在信道 3 时，信道 9 会出现约 0.66 的镜像伪评分；不影响跟最强的那个，但空场可能误锁。
- `--mock` 与实机都用同一套跟踪逻辑，只是信号源不同。
- 需要独占 X310：同一时刻只能开一个实例。
